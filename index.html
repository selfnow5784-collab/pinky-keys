Pinky's Auto Reference and Inventory (v3.9). Offline key reference and in-stock lookup for Pinky's Locksmithing.

Type year, make or model in the search box (a year finds ranges like 2014-2018). Filters opens chips; tap Done to close.

On a computer, File / Edit / View / Help is at the top. On a phone, ☰ opens the same menu. The Reference screen stays search, Filters and the sheet.

Tick rows to Print, mark in stock, Hide or Export just those. Edit → + Add item adds your own row (Source: My item). Hide is reversible from View → Hidden rows (or Undo). Supplier rows are only hidden, never deleted; your items can be deleted from the card.

⚙ at the end of the header picks columns, including ones you add (Bin location, Cost, …). Print and Export use what is on screen (or the selection).

Tap a row for the details card. Amber dot = needs review; the card says why. Edit or Confirmed ✓ saves into My Fixes. Export My Fixes and send the file so it can be combined into the next CSV update.

Data stays on this phone and works offline. Blank = the supplier did not show it.
