Search: tables only (no answer line): Inventory, Reference keys, Chips; the In stock column says Yes (n) / No. Tap a header to sort (again = reverse). Tap a cell to edit it (edits the real record; Save keeps it). Tap the Fits number of a key to list every vehicle it fits.

Inventory = what is in the van (in stock); the only source of stock qty. Reference = supplier catalog, not stock. In stock column: "Yes (n)" = an Inventory item with qty n links to that key by part #/FCC; "No" = not in stock. Vehicles = chip per vehicle.

* after a number = model name cut off in the source file. Supplier qty is the supplier's number, not yours.

Save button: red = unsaved, green = saved. Data stays on this phone; works offline.
